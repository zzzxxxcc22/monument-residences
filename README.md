# MONUMENT

Портфолийный сайт премиального жилого комплекса в Хамовниках. Дизайн основан на предоставленном moodboard-референсе и переработан в полноценный адаптивный лендинг с оригинальными архитектурными изображениями.

## Возможности

- полноэкранный архитектурный hero и модульная editorial-композиция;
- каталог четырёх типов резиденций;
- интерактивный выбор этажей и доступности;
- переключаемая галерея интерьеров;
- планировка, инфраструктура, ход строительства и карта;
- мобильное меню с поддержкой Escape;
- форма заявки с доступной клиентской валидацией;
- адаптивность от 320 px и поддержка `prefers-reduced-motion`.

## Стек

Next.js 16, React 19, TypeScript, CSS Modules, Vitest и Testing Library.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Открыть `http://localhost:3000`.

## Проверки

```bash
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```

## Структура контента

- `data/site.ts` — резиденции, этажи, галерея и преимущества;
- `components/` — независимые смысловые секции и интерактивы;
- `public/images/` — локальные оптимизированные изображения и SVG;
- `reference/monument-reference.png` — исходный визуальный ориентир.

Проект является концептуальной работой для портфолио и не представляет реальный объект недвижимости.
